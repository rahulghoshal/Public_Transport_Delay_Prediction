# 🚍 Public Transport Delay Prediction

A machine learning project that predicts whether a public transport trip (Bus, Train, Tram, or Metro) will be **delayed** or **not delayed**, based on route, weather, traffic, and scheduling information. The trained model is served through an interactive **Streamlit** web app.

---

## 📁 Project Structure

```
.
├── Classifier_model.ipynb        # EDA, feature engineering, model training & evaluation
├── app.py                        # Streamlit app for live predictions
├── public_transport_delays.csv   # Dataset used for training
├── transport_delay_model.pkl     # Trained model (generated by the notebook)
└── README.md
```

## 📊 Dataset

The dataset (`public_transport_delays.csv`) contains simulated trip records with the following fields:

| Category | Columns |
|---|---|
| Trip info | `trip_id`, `date`, `time`, `transport_type`, `route_id`, `origin_station`, `destination_station` |
| Schedule | `scheduled_departure`, `scheduled_arrival` |
| Delay values | `actual_departure_delay_min`, `actual_arrival_delay_min` |
| Weather | `weather_condition`, `temperature_C`, `humidity_percent`, `wind_speed_kmh`, `precipitation_mm` |
| Context | `event_type`, `event_attendance_est`, `traffic_congestion_index`, `holiday`, `peak_hour`, `weekday`, `season` |
| Target | `delayed` (0 = No Delay, 1 = Delayed) |

---

## 🔍 Workflow (`Classifier_model.ipynb`)

1. **Exploratory Data Analysis** — trends in delay by hour, day, transport type, weather, events, and traffic congestion, plus a correlation heatmap.
2. **Preprocessing**
   - Parsed `date`/`time` into `year`, `month`, `day`, `hour`.
   - Filled missing `event_type` values with `"No Event"`.
   - One-hot encoded low-cardinality categorical columns: `transport_type`, `weather_condition`, `event_type`, `season`.
   - Label-encoded high-cardinality columns: `route_id`, `origin_station`, `destination_station`.
3. **Model** — `RandomForestClassifier` (scikit-learn), trained on an 80/20 train-test split.
4. **Evaluation** — accuracy, precision, recall, confusion matrix, classification report, and 5-fold cross-validation.
5. **Export** — the trained model is saved with `joblib` as `transport_delay_model.pkl` for use in the Streamlit app.

### ⚠️ Note on model performance
The current model reaches **100% accuracy** on both the test set and cross-validation. This is unusually high and is a strong signal of **data leakage** — most likely because `actual_arrival_delay_min` (which is used as an input feature) is highly correlated with, or was used to derive, the `delayed` target itself, and it also dominates the feature importance ranking. Before using this model for anything beyond a demo, it's worth re-training **without** the `actual_departure_delay_min` / `actual_arrival_delay_min` features, so the model instead learns from genuinely predictive signals like weather, traffic, and schedule.

## 🖥️ Streamlit App (`app.py`)

The app collects trip details through form inputs (route, stations, weather, traffic, event info, schedule, etc.), builds a single-row DataFrame matching the model's training features (including one-hot encoded columns), and returns a **Delay** / **No Delay** prediction when you click **"Predict Delay or No Delay."**

## ⚙️ Setup & Installation

1. **Clone/download the project files** and make sure `transport_delay_model.pkl` is in the same folder as `app.py` (generate it by running the notebook if it isn't already there).

2. **Install dependencies:**
   ```bash
   pip install streamlit pandas numpy scikit-learn joblib matplotlib seaborn
   ```

3. **Run the notebook** (only needed if you want to retrain the model):
   ```bash
   jupyter notebook Classifier_model.ipynb
   ```

4. **Launch the Streamlit app:**
   ```bash
   streamlit run app.py
   ```

5. Open the local URL Streamlit prints in your terminal (usually `http://localhost:8501`).

---

## 🚀 Usage

1. Fill in the trip details in the sidebar/form — route, stations, weather conditions, traffic index, event info, and scheduled/actual times.
2. Click **"Predict Delay or No Delay."**
3. The app displays:
   - ✅ **No Delay** — if the model predicts on-time arrival.
   - ⚠️ **Delay** — if the model predicts a delay.
